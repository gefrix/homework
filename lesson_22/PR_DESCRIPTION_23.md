# Домашняя работа 23 «Работа с ORM в Django»

## Изменения

- подключена PostgreSQL, настройки вынесены в переменные окружения;
- добавлены зависимости `psycopg2-binary`, `Pillow` и `ipython`;
- созданы модели категорий, товаров и контактных данных с миграциями;
- товар связан с категорией, поддерживает изображение и даты создания/изменения;
- настроена административная панель: списки, фильтр товаров по категории и поиск;
- добавлены фикстура и команда `load_catalog_data` с очисткой старых данных;
- главная страница показывает последние пять товаров, контакты загружаются из базы;
- добавлены тесты и скриншоты операций Django ORM.

## Проверка

- `python manage.py check`;
- `python manage.py makemigrations --check`;
- `python manage.py test catalog`;
- `python manage.py loaddata catalog_data`;
- `python manage.py load_catalog_data`;
- ручная проверка каталога, контактов и административной панели.
