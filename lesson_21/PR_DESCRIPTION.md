# Домашняя работа 21.2 «Основы вёрстки»

## Цель

Собрать Bootstrap-интерфейсы по учебным прототипам и реализовать простое веб-приложение без фреймворков.

## Изменения

- добавлены страницы «Главная», «Каталог», «Категория 1» и «Контакты»;
- Bootstrap 5 подключён через CDN;
- добавлен Python HTTP-сервер, возвращающий HTML с корректным `Content-Type`;
- реализован приём POST-запроса формы и вывод полученных данных в консоль;
- добавлены страницы ошибок 404 и 500;
- добавлены инструкция по запуску и `.gitignore`.

## Проверка

- сервер запускается командой `py server.py`;
- любой GET-запрос возвращает страницу «Контакты»;
- отправка формы возвращает HTTP 200 и печатает поля формы в консоль;
- неизвестный POST-маршрут возвращает HTTP 404.
