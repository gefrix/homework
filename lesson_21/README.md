# Домашняя работа 21.2 — основы вёрстки

Проект содержит четыре HTML-страницы по прототипам из задания и простой HTTP-сервер на стандартной библиотеке Python.

## Что реализовано

- `index.html` — главная страница с карточками товаров;
- `catalog.html` — каталог с широкими карточками;
- `category.html` — страница категории с шестью товарами;
- `contacts.html` — страница контактов и форма обратной связи;
- Bootstrap 5 и Bootstrap Icons подключены с CDN;
- `server.py` возвращает страницу «Контакты» на любой GET-запрос;
- POST-запрос формы принимается сервером, а данные печатаются в консоль;
- после успешной отправки формы пользователь видит уведомление;
- для неизвестного POST-адреса возвращается страница 404, для ошибки обработки — страница 500;
- HTML-файлы читаются через контекстный менеджер `with open()`;
- `.gitignore` содержит все элементы из критериев задания.

## Запуск

Требуется Python 3.10 или новее. Сторонние Python-библиотеки не нужны.

```powershell
cd C:\Users\ayanchuk\Documents\Sky.pro\homework\lesson_21
py server.py
```

После запуска откройте в браузере:

```text
http://localhost:8080
```

Для остановки сервера нажмите `Ctrl+C`.

## Проверка POST-запроса

Заполните форму на странице «Контакты» и нажмите «Отправить». В консоли появится вывод примерно такого вида:

```text
Получены данные POST-запроса:
name: Анна
email: anna@example.com
message: Хочу задать вопрос
```
